# Expense Tracker

A simple and responsive expense tracker built with HTML, CSS, and vanilla JavaScript.

## Features

* Add expenses with a description, amount, and category
* Delete expenses
* Filter expenses by category
* Calculate total expenses
* Save expenses using `localStorage`
* Persist expenses after refreshing the page
* Responsive layout
* Dark theme

## Built With

* HTML5
* CSS3
* JavaScript
* Browser `localStorage`

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No dependencies or build tools are required.
